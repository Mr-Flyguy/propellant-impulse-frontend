# Propellant Impulse Explorer

Клиентское веб-приложение (Single Page Application) на React 19, TypeScript и Vite для интерактивной визуализации характеристик рабочих тел ядерных ракетных двигателей и просмотра динамики истечения реактивной струи.

---

## Страницы приложения

В приложении предусмотрено 4 экрана, переключение между которыми осуществляется через нижнюю панель навигации (в гостевом режиме доступны просмотровые экраны «Лента» и «Плитка»).

### 1. Экран «Лента» (`#/feed`, `#/feed/:id`)
Полноэкранный просмотр видеозаписи истечения реактивной струи и физических параметров выбранного рабочего тела.
* **Отображаемые элементы и поля**:
  * Видеоплеер с зацикленным воспроизведением струи (с автоматическим переключением на резервный локальный ролик при сетевых ошибках);
  * Название рабочего тела (например, Жидкий водород, Метан и др.);
  * Информационные бейджи параметров: молярная масса (г/моль), показатель адиабаты, количество отметок одобрения;
  * Раскрывающийся блок подробного инженерного описания вещества.
* **Кнопки и управление**:
  * Кнопка **«Далее >»** — перелистывание к следующему рабочему телу в списке;
  * Спойлер **«Инженерное описание»** — раскрытие и скрытие подробного текста.

### 2. Экран «Добавление» (вкладка «ДОБАВИТЬ»)
Форма создания и регистрации нового рабочего тела в каталоге.
* **Статус**: отключена в гостевом режиме (кнопка в панели навигации заблокирована).
* **Поля формы**:
  * Поле ввода названия вещества (`name`);
  * Поле ввода молярной массы (`molarMass`);
  * Поле ввода показателя адиабаты (`specificHeatRatio`);
  * Текстовая область описания (`description`);
  * Поле ссылки на изображение превью (`imageUrl`);
  * Поле ссылки на видеозапись истечения струи (`videoUrl`).
* **Кнопки**:
  * Кнопка **«Сохранить черновик»**;
  * Кнопка **«Опубликовать»**.

### 3. Экран «Плитка» (`#/catalog`)
Каталог рабочих тел в виде двухколоночной плиточной сетки с фильтрацией.
* **Отображаемые элементы и поля**:
  * Ползунок ограничения максимальной молярной массы (диапазон 1.00–64.00 г/моль);
  * Числовой индикатор выбранного порогового значения;
  * Карточки веществ: превью (с автоматическим fallback на изображение по умолчанию), название, молярная масса, показатель адиабаты и счетчик отметок.
* **Кнопки и управление**:
  * Кнопка **«Фильтр»** — применение заданного ограничения по массе;
  * **Карточка вещества** — клик по карточке осуществляет переход к её полноэкранному просмотру в экране «Лента».

### 4. Экран «Вход» (вкладка «ВХОД»)
Форма аутентификации инженера-исследователя в системе.
* **Статус**: отключена в гостевом режиме (кнопка в панели навигации заблокирована).
* **Поля формы**:
  * Поле ввода имени пользователя / логина (`username`);
  * Поле ввода пароля (`password`).
* **Кнопки**:
  * Кнопка **«Войти»**;
  * Кнопка перехода к регистрации нового пользователя.

## Навигационная панель (`NavbarBottom`)

Фиксированная нижняя панель навигации содержит 4 пункта:
1. **ЛЕНТА** — активный переход к видеоплееру;
2. **ДОБАВИТЬ** — заблокировано в гостевом режиме;
3. **ПЛИТКА** — активный переход к каталогу;
4. **ВХОД** — заблокировано в гостевом режиме.

## Запуск проекта

### Требования
* Node.js 20+
* npm 10+

### Установка и запуск
```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (по умолчанию http://localhost:5173/)
npm run dev

# Проверка типов и production-сборка
npm run build
```
